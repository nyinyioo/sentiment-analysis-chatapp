# Sentiment Analysis Chat App

### Set-Up Instructions
Requirements:
- Python 3.10+
- Node.js
- Docker
- Rasa
- Transformers
- Torch

```bash

#Clone Repo
git clone <repo-url>
cd nav-bot

# Backend Install Node
cd backend/app
npm install
cd ../..

# Backend Install Requirements
python -m venv venv
source venv/bin/activate
pip install -r backend/requirements.txt

# Start everything
./scripts/start.sh
```
