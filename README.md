# Sentiment Analysis Chat App

### Set-Up Instructions
Requirements:
- Python
- Node.js 
- Docker
- Rasa
- Transformers
- Torch
  
```bash
git clone <repo-url>
cd nav-bot
python -m venv venv
source venv/bin/activate
pip install -r backend/requirements.txt
cd backend/app
npm install
cd ../..
./scripts/start.sh
```
